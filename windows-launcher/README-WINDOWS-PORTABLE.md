# Direct-Xfer 1.66.0 — Windows portable

`Direct-Xfer.exe` is the .NET 10 (`net10.0-windows`) WinForms tray/launcher UI. `Direct-Xfer.ServerHost.exe` is a .NET 10 Windows host that supervises the bundled Node.js runtime and the Direct-Xfer backend.

The portable package generated by GitHub Actions contains:
- `Direct-Xfer.exe`
- `Direct-Xfer.ServerHost.exe`
- `runtime/app` — Direct-Xfer 1.66.0 application runtime
- `runtime/node/node.exe` — pinned official x64 Node.js runtime
- `runtime/rclone/rclone.exe` — bundled official rclone v1.74.4 Windows AMD64 for storage connectors

This stage of the migration intentionally remains **framework-dependent**: Windows must have the **.NET 10 Desktop Runtime x64 (projets SDK modernes, C# 14)** installed. A later self-contained publication can remove that prerequisite without changing the application code.

The application is intentionally unsigned. Runtime state is stored under `%LOCALAPPDATA%\Direct-Xfer` and the folders selected during first-run setup.


Download the required runtime from Microsoft:
`https://dotnet.microsoft.com/en-us/download/dotnet/10.0`

Or install it with WinGet:
`winget install Microsoft.DotNet.DesktopRuntime.10`


## Storage connectors on Windows

The Windows package includes rclone; no separate rclone installation or PATH configuration is required. Direct-Xfer automatically uses `runtime\rclone\rclone.exe` and keeps the rclone configuration under `%LOCALAPPDATA%\Direct-Xfer\data\rclone\rclone.conf`.

To create or edit cloud remotes manually, run from PowerShell:

```powershell
& "$env:ProgramFiles\Direct-Xfer\runtime\rclone\rclone.exe" config --config "$env:LOCALAPPDATA\Direct-Xfer\data\rclone\rclone.conf"
```

## OCR / Tesseract

The Windows package bundles Tesseract OCR 5.5.3 under `runtime\tesseract`. Direct-Xfer uses it automatically through ServerHost, including the `eng`, `fra` and `spa` language models. No separate Tesseract installation or PATH change is required for image OCR.

Scanned-PDF OCR additionally requires Poppler (`pdftoppm`); searchable PDFs can still use their embedded text layer without Poppler.
