Auditors can view but not change anything.

    Configuration
    
          
        
    
        
    
          
    Security
    
          
          
          
    Locks the admin interface (requires signing in again) after this long with no mouse or keyboard activity.
    
          
    
            
            
          
    
          
    
            
            
          
    
          
          
          
          
    Managed by the ADMIN_ALLOWED_IPS environment variable.
    
          
    Leave empty to keep the default (local network). Loopback is always allowed. A wrong entry can lock you out.
    

          
          
    Blocks a public upload/delete client temporarily after mass deletion or a ransomware-like upload burst. It never deletes files automatically.
    
          
          
    
            
            
            
          
    
          
    
          
    

          
    Data Loss Prevention (DLP)
    
          
          
    Local scan before publishing a share. Detected secrets are redacted in logs and the interface.

    Créez une alerte lorsqu’un de vos liens atteint un seuil précis.
    
            
    
              
              
              
              
            
    
            
    
            
    
          
    

          
    Notifications (webhook)
    
          
    Managed by the WEBHOOK_URL environment variable.
    
          
          
          
    
            
            
            
          
    
          
          
    
            
            
          
    

          
    Browser notifications (Web Push)
    
          
    Web Push is unavailable: the web-push module isn't installed on the server.
    
          
    Requires a secure context (HTTPS, or localhost). Enable TLS to use browser push.
    
          
    Receive push notifications in this browser for the events ticked above — even when the admin page is closed. Each browser/device subscribes separately.
    
          
    
            
            
            
          
    

          
          
          
          
          
    
            
            
          
    
          
    Both alerts use the webhook above. Save your changes before testing.
    
          

          
    E-mail notifications (SMTP)
    
          
    Managed by the SMTP_URL environment variable.
    
          
    The nodemailer module is unavailable; e-mail is disabled.
    
          
          
    
            
            
          
    
          
          
    
            
            
          
    
          
          
          
    
            
            
          
    

          
    Defaults for new links
    
          
          
    The "New share" file picker opens here. Leave empty to reuse the last-browsed folder.
    
          
          
          
    
            
            
            
          
    
          
          
          
          
          
          
    
            
            
            
            
            
          
    
          
          

          
    Reception-link defaults
    
          
    
            
            
            
          
    
          
          
          

          
    Global limits
    
          
          
    Hard ceiling applied to every download, on top of any per-link limit.
    
          
    
            
            
            
            
          
    
          
          
    
            
            
            
          
    
          
    Server-local time. The window may span midnight (e.g. 08:00 → 02:00). Outside it, only the caps above apply.
    

          
    Public download protection
    
          
          
    
            
            
          
    
          
          
    
            
            
          
    
          
    A self-hosted proof-of-work solved in the visitor's browser (no third party). Deters mass scraping of a leaked link; higher difficulty = more work per download.
    
          
          
    
            
            
          
    
          
    Sends one notification (over the webhook / e-mail above) when a single link is downloaded from at least this many countries in the window — a sign the link may have leaked. Needs IP geolocation enabled.
    

          
    Privacy
    
          
          
    Off = no external lookups; visitor countries won't be shown.
    
          
          
          
          
    ⚠ Destructive: permanently deletes reception & collaboration files older than this — lost files cannot be recovered. Off by default.
    
          
          
          
    Keeps old links out of the main list without changing or deleting their managed files.
    
          
          
    ⚠ Destructive: removes Direct-Xfer-managed copies for expired links (received files, images, encrypted blobs). Host source files are never deleted.
    
          
          
          
    
            
            
          
    

          
    Interface
    
          
          
          
          
          
    Tints the mobile browser UI bar on public pages (meta theme-color).
    
          
    
            
            
          
    
          
          
    Comma-separated durations offered in the link modals — e.g. 6h, 3d, 2w, 1mo. “Never” is always available.
    
          
          
          
    Shown in the top bar of public pages. PNG/JPG/GIF/WebP/SVG, up to ~200 KB.
    
          
          
          
    Shown as a banner on every public download / reception page.
    
          
          
    Overlays the visitor IP (or recipient name for nominative links) over previews — deters re-sharing of screenshots.
    

          
    Maintenance
    
          
          
    Compares the running version against the latest published image tag. No data is sent beyond the version query.
    

          
    Emergency stop
    
          
    Immediately pause every active link (reversible). Files are left untouched.
    
          
    
            
            
            
          
    

          
    Backup & restore
    
          
    
            
            
            
            
          
    
          
    
            
            
            
            
          
    
          
    Exports every link's settings (paths, quotas, expiries, passwords) — not the files. Useful to migrate links to another server.
    
          
    
            
            
            
          
    
          
    The admin action log (logins, link create/revoke, settings changes, alerts).
    

          
    Scheduled full backup
    
          
    A full backup bundles the whole store (links + settings), the transfer journal and the secret notes into one file — encrypted with DATA_KEY when it's set. Pushed to a folder, WebDAV or S3.
    
          
          
    
            
            
            
          
    
          
          
    
            
            
    Mount a writable host folder into the container (e.g. /backups) so backups survive a container recreation.
    
          
    
          
    
            
            
    
              
              
            
    
          
    
          
    
            
            
    
              
              
              
            
    
            
    
              
              
            
    
          
    
          
          
    ⚠ DATA_KEY is not set: backups are stored in PLAINTEXT (they contain password hashes and secret notes). Set DATA_KEY to encrypt them.
    
          
    
            
            
            
            
          
    
          
    
            
            
            
          
    
          
    
          
    Save your settings before using Backup now / Test. Restore replaces everything and cannot be undone.
    
          
    

          
    Storage connectors
    
          
    Import and export files through an rclone remote: SFTP, SMB, WebDAV, Google Drive, OneDrive, Dropbox or Box. Credentials stay in /data/rclone/rclone.conf.
    
          
    
          
    
            
    
              
              
              
              
            
    
            
            
            
    
          
    
          
    
          
    
            
            
    
              
              
            
    
            
    For import, the local field is an optional path below /Direct-Xfer/Imports. For export, enter an existing host, reception or image path.
