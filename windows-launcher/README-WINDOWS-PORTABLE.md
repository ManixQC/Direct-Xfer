# Direct-Xfer 1.66.3 — Windows portable

`Direct-Xfer.exe` is the .NET 10 (`net10.0-windows`) WinForms tray/launcher UI. `Direct-Xfer.ServerHost.exe` is the .NET 10 Windows host that supervises the bundled Node.js runtime and the Direct-Xfer backend. Both executables are published **framework-dependent single-file for win-x64** and are pinned to the private shared runtime under `runtime/dotnet`.

The portable package generated by GitHub Actions contains:
- `Direct-Xfer.exe`
- `Direct-Xfer.ServerHost.exe`
- `runtime/app` — Direct-Xfer 1.66.3 application runtime
- `runtime/node/node.exe` — pinned official x64 Node.js runtime
- `runtime/dotnet` — one private shared .NET 10 runtime tree used by both Windows EXEs (base Runtime + WindowsDesktop framework)
- `runtime/rclone/rclone.exe` — bundled official rclone v1.74.4 Windows AMD64 for storage connectors
- `runtime/tesseract/tesseract.exe` — bundled Tesseract OCR 5.5.3 with `eng`, `fra` and `spa` models

Direct-Xfer bundles **one private .NET 10 runtime tree x64** under `runtime\dotnet`. GitHub Actions assembles that tree by merging Microsoft's matching `dotnet-runtime` archive (host + `Microsoft.NETCore.App`) with the `windowsdesktop-runtime` archive (`Microsoft.WindowsDesktop.App`). Both `Direct-Xfer.exe` and `Direct-Xfer.ServerHost.exe` resolve only this app-relative runtime through `AppHostDotNetSearch=AppRelative`, so the runtime is stored once instead of being duplicated inside both EXEs. **No separate Microsoft .NET Runtime or Desktop Runtime installation is required on Windows.**

The application is intentionally unsigned. Runtime state is stored under `%LOCALAPPDATA%\Direct-Xfer` and the folders selected during first-run setup.


## Storage connectors on Windows

The Windows package includes rclone; no separate rclone installation or PATH configuration is required. Direct-Xfer automatically uses `runtime\rclone\rclone.exe` and keeps the rclone configuration under `%LOCALAPPDATA%\Direct-Xfer\data\rclone\rclone.conf`. Explicit `RCLONE_BIN` and `RCLONE_CONFIG` environment overrides are preserved.

To create or edit cloud remotes manually, run from PowerShell:

```powershell
& "$env:ProgramFiles\Direct-Xfer\runtime\rclone\rclone.exe" config --config "$env:LOCALAPPDATA\Direct-Xfer\data\rclone\rclone.conf"
```

## OCR / Tesseract

The Windows package bundles Tesseract OCR 5.5.3 under `runtime\tesseract`. Direct-Xfer uses it automatically through ServerHost, including the `eng`, `fra` and `spa` language models. No separate Tesseract installation or PATH change is required for image OCR. Explicit `SEARCH_OCR_TESSERACT_BIN` and `TESSDATA_PREFIX` environment overrides are preserved. For the bundled engine, Direct-Xfer points Tesseract at `runtime\tesseract\tessdata` explicitly so language discovery does not depend on Windows environment-variable interpretation.

Scanned-PDF OCR additionally requires Poppler (`pdftoppm`); searchable PDFs can still use their embedded text layer without Poppler.
